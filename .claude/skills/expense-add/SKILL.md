# expense-add

支出を `data/finance.json` の `expense_entries` に1件追加する。

## 手順

1. 依頼文から次の項目を読み取る。
   - `date`: 日付。`YYYY-MM-DD` 形式。「昨日」などは今日の日付から計算する。指定なしは今日の日付
   - `amount`: 金額(円)。無ければユーザーに聞く
   - `memo`: 用途のメモ。「コンビニ」「ガソリン」など。分からなければ空文字 `""`(聞き返さない)
2. `data/finance.json` を読む。形式は `{"income_entries": [], "expense_entries": [], "bills": [], "known_rates": {}}`。
3. 次の1件を `expense_entries` の末尾に追加する。
   ```json
   {
     "id": 通し番号(expense_entriesの既存の最大id + 1。空なら1),
     "date": "YYYY-MM-DD",
     "amount": 1200,
     "memo": "コンビニ",
     "created_at": "今日の日付 YYYY-MM-DD"
   }
   ```
4. 見やすい形(インデント2)で書き戻す。`expense_entries` 以外の部分と既存の記録は変更しない。
5. 日本語で「#番号 〇月〇日 〇〇円(メモ)を追加しました(今月の支出合計 〇〇円)」と報告する。メモが空なら「(メモなし)」と書く。今月の支出合計は、今日が含まれる月の `date` のものだけを足す。

## 守ること

- 操作の前に、何をするかを専門用語なしの日本語で説明する。
- 書き込む前に、JSONが壊れていないか確認する。壊れていたら書き込まず報告する。
- 家賃など `bills`(固定費)に入っているものは、毎月の集計で別に数えるため、ここには入れない。固定費の支払い済みを記録したいと言われたら、ユーザーに確認する。
- 同じ日付・同じ金額・同じメモの記録が既にある場合は、二重登録かもしれないので、追加する前にユーザーに確認する。
