# task-add

タスクを `data/tasks.json` に1件追加する。

## 手順

1. 依頼文から次の項目を読み取る。足りないものは聞き返さず、下記の初期値を使う。
   - `title`: タスクの内容(必須。無ければユーザーに聞く)
   - `due`: 期限。`YYYY-MM-DD` 形式。「明日」「来週金曜」などは今日の日付から計算する。指定なしは `null`
   - `priority`: `high` / `medium` / `low`。指定なしは `medium`
2. `data/tasks.json` を読む。形式は `{"tasks": [ ... ]}`。
3. 次のタスクを `tasks` の末尾に追加する。
   ```json
   {
     "id": 通し番号(既存の最大id + 1。空なら1),
     "title": "...",
     "due": "YYYY-MM-DD または null",
     "priority": "medium",
     "status": "todo",
     "created_at": "今日の日付 YYYY-MM-DD"
   }
   ```
4. 見やすい形(インデント2)で書き戻す。既存のタスクは変更しない。
5. 追加した内容を、日本語で「#番号 タイトル(期限・優先度)を追加しました」と報告する。

## 守ること

- 操作の前に、何をするかを専門用語なしの日本語で説明する。
- 書き込む前に、JSONが壊れていないか確認する。壊れていたら書き込まず報告する。
- 同じタイトルで未完了のタスクが既にある場合は、追加する前にユーザーに確認する。
