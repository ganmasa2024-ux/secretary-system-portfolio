# task-list

`data/tasks.json` のタスクを、ユーザーが見やすい形で表示する。表示だけで、ファイルは変更しない。

## 手順

1. `data/tasks.json` を読む。形式は `{"tasks": [ ... ]}`。
2. 依頼に合わせて絞り込む。指定がなければ `status` が `todo` のものだけ表示する。
   - 「全部」→ 完了済みも含める
   - 「今日」→ 期限が今日、または期限切れのもの
   - 「優先度高」→ `priority` が `high` のもの
3. 次の順に並べる: 期限が近い順(期限なしは最後)→ 優先度が高い順。
4. 表で表示する。
   | # | やること | 期限 | 優先度 |
   |---|---|---|---|
5. 期限切れのものには「⚠ 期限切れ」と添える。
6. 最後に「未完了◯件(うち期限切れ◯件)」と一行でまとめる。タスクが0件なら「今のところタスクはありません」と伝える。

## 守ること

- 優先度は `high`=高、`medium`=中、`low`=低 と日本語で表示する。
- 操作の前に、何をするかを専門用語なしの日本語で説明する。
