# money-summary

`data/finance.json` から、対象の月の収支と、直近の支払いまでに必要な金額を計算して伝える。表示だけで、ファイルは変更しない。

## ファイルの形

```json
{
  "income_entries": [{"id": 1, "date": "2026-10-22", "source": "アルバイト", "hours": 3, "amount": 3690, "created_at": "..."}],
  "expense_entries": [{"id": 1, "date": "2026-10-22", "amount": 1200, "memo": "コンビニ", "created_at": "..."}],
  "bills": [{"name": "家賃", "amount": 55000, "frequency": "monthly", "day_of_month": "month_end", "bank": "A銀行", "shift_weekend": true}],
  "known_rates": {"アルバイト": 1230}
}
```

- `bills` は毎月かかる固定費。`day_of_month` は毎月の支払日で、数字(1〜31)か文字列 `"month_end"` が入る。
  - `"month_end"` は「その月の最終日」。対象の月の最終日を計算して使う(例: 10月なら31日、11月なら30日、2月なら28日または29日)。
  - 数字が月の日数より大きい場合も、その月の最終日として扱う。
  - `bank` は支払元(銀行名、または「振込」などの支払い方法)。
  - `shift_weekend` は土日調整が必要かどうか。`true`(銀行振込・口座引き落とし)は、支払日が土曜・日曜に当たる月だけ、次の月曜に実際の支払日をずらす。`false`(デビットカード払い)は、土日でも支払日のまま変えない。項目が無い固定費は `false` と同じに扱い、土日でもずらさない。祝日は考えない(土日だけ)。
  - ずらした後の日付を「実際の支払日」と呼ぶ。月をまたいでもよい(例: 10月31日が土曜なら、実際の支払日は11月2日)。
- `bills` が空のときは、固定費がまだ登録されていないと伝え、名前・金額・支払日・支払元を聞いて登録するか確認する(勝手に作らない)。

## 手順

1. 集計する月を決める。
   - 指定なし・「今月」→ 今日の日付が含まれる月
   - 「先月」→ その前の月
   - 「9月」など → その月(年は今日に最も近い過去か今年)
2. `data/finance.json` を読む。
3. `income_entries` と `expense_entries` から、`date` が対象の月(`YYYY-MM`)のものだけを取り出して合計する。他の月の記録は集計に入れない(消さない)。
4. 計算する。
   - 収入合計 = 対象の月の収入の合計
   - 支出合計 = 対象の月の支出の合計
   - 固定費合計 = `bills` の金額の合計
   - 今月の収支 = 収入合計 − 支出合計 − 固定費合計
   - 今使えるお金 = 収入合計 − 支出合計 − (まだ支払っていない固定費の合計)
5. 「直近の支払いまで」を計算する(今月、または今日が含まれる月のとき)。
   - 今日以降で、いちばん近い「実際の支払日」の固定費を探す(`"month_end"` はその月の最終日として計算し、`shift_weekend` が `true` のものは土日なら次の月曜にずらしてから比べる)(今日が支払日ならその日も含む)。前月・今月・来月の3か月分を計算して、今日以降で最も早いものを選ぶ(前月末の支払いが今月にずれ込むことがあるため)。
   - 「〇〇までにあと必要な額」= その固定費の金額 − 今使えるお金。ただし0未満なら0(足りている)。
   - 時給が `known_rates` にあれば、「アルバイトなら約〇時間分」(必要額 ÷ 時給を切り上げ)も添える。
   - 支払日の前に、同じ期間で他の固定費も重なる場合は、まとめて必要額を出す。
6. 日本語で、次の形で表示する。
   ```
   【2026年10月の収支】
   収入    〇〇円(アルバイト 〇時間 ほか)
   支出    〇〇円
   固定費  〇〇円(家賃 〇〇円 ほか)
   ──────────
   収支    +〇〇円 / −〇〇円

   【次の支払い】家賃 〇〇円(10/27・あと〇日)
   今使えるお金 〇〇円 → あと〇〇円必要(アルバイトなら約〇時間)
   ```
   固定費の一覧を聞かれたときは、対象の月の実際の支払日の早い順に「名前・金額・支払日(月末は実際の日付も)・支払元」と合計を表示する。土日でずれた固定費は「10/31(土)→11/2(月)」のように、元の日とずらした後の日を並べて書く。ずらさない固定費は、土日でもそのままの日付で書く。

   過去の月を聞かれたときは「次の支払い」は出さず、その月の収支だけを表示する。
7. 記録が1件も無い月は、「〇月の記録はまだありません」と伝える。

## 守ること

- 操作の前に、何をするかを専門用語なしの日本語で説明する。
- 計算の元になった数字(収入何件、支出何件など)も添えて、どこから出した数字か分かるようにする。
- 実データの金額は、ポートフォリオなど人に見せる場には出さない(CLAUDE.mdのルール)。
