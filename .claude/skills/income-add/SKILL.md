# income-add

収入を `data/finance.json` の `income_entries` に1件追加する。

## 手順

1. 依頼文から次の項目を読み取る。
   - `date`: 日付。`YYYY-MM-DD` 形式。「昨日」などは今日の日付から計算する。指定なしは今日の日付
   - `source`: 収入源。「アルバイト」など。言われなければ `アルバイト`(現在の主な収入源)
   - `hours`: 働いた時間。言われなければ `null`
   - `amount`: 金額(円)。
     - 金額が言われた場合はそのまま使う
     - 時間だけ言われた場合は `known_rates` の時給 × 時間で自動計算する(アルバイト=1230円)
     - 金額も時間も無い、または時給が `known_rates` に無い場合は、ユーザーに聞く
2. `data/finance.json` を読む。形式は `{"income_entries": [], "expense_entries": [], "bills": [], "known_rates": {}}`。
3. 次の1件を `income_entries` の末尾に追加する。
   ```json
   {
     "id": 通し番号(income_entriesの既存の最大id + 1。空なら1),
     "date": "YYYY-MM-DD",
     "source": "アルバイト",
     "hours": 3,
     "amount": 3690,
     "created_at": "今日の日付 YYYY-MM-DD"
   }
   ```
4. 見やすい形(インデント2)で書き戻す。`income_entries` 以外の部分と既存の記録は変更しない。
5. 日本語で「#番号 〇月〇日 アルバイト 〇時間 〇〇円を追加しました(今月の収入合計 〇〇円)」と報告する。今月の収入合計は、今日が含まれる月の `date` のものだけを足す。

## 守ること

- 操作の前に、何をするかを専門用語なしの日本語で説明する。
- 書き込む前に、JSONが壊れていないか確認する。壊れていたら書き込まず報告する。
- 時給から計算した場合は、「時給〇〇円 × 〇時間」と計算の中身も伝える。
- 同じ日付・同じ収入源・同じ金額の記録が既にある場合は、二重登録かもしれないので、追加する前にユーザーに確認する。
