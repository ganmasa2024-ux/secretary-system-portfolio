# secretary-system

Claude Code を中心に作った、個人用の秘書システムです。日々のタスク管理、簡単な家計管理(収入・支出・固定費)、Google カレンダーとの連携を、Claude Code との会話だけで行います。

専用のアプリや画面はありません。「タスク追加して」「今月の収支教えて」「おはよう」と話しかけると、Claude Code がデータファイルを読み書きして答えます。

> この README と `samples/` には、実際の家計・タスクのデータは載せていません。データの形は `samples/` の架空データで確認できます。

## アーキテクチャ

3つのレイヤー(層)に分けて作っています。

### 1. 知識レイヤー: `CLAUDE.md`
プロジェクトの目的、使う人のプロフィール、守るルール(認証情報をコミットしない、実データを人に見せない、など)、そして「いつ何を自動で実行するか」を書いた引き継ぎノートです。Claude Code は会話の最初にこれを読み、毎回同じ前提で動きます。

### 2. 実行レイヤー: スキル + MCP 連携
- **スキル**: 1つの作業(タスク追加、収支の集計など)を、手順書(`.claude/skills/*/SKILL.md`)として1つにまとめたものです。依頼の言葉に応じて Claude Code が選んで実行します。
- **MCP 連携**: Google カレンダーと Google スプレッドシートを、Claude Code から直接読み書きするための接続です。

### 3. 知性レイヤー: 自動振り返り・月次まとめ
- 会話を締めくくる言葉(「お疲れ様でした」など)を言うと、その日にやったことを自動で振り返りファイルに追記します。
- 月が変わった最初の会話で、前の月の振り返りをまとめるかどうかを提案します。

## 作成したスキル(9つ)

### タスク管理
- **task-add(タスク追加)**: やることをリストに追加する。期限や優先度も一緒に記録する
- **task-list(タスク一覧)**: 残っているタスクを一覧で表示する

### 家計管理
- **income-add(収入追加)**: 働いた分の収入を記録する。時間だけ伝えると、時給から金額を自動で計算する
- **expense-add(支出追加)**: 使ったお金を記録する
- **money-summary(収支の集計)**: 月ごとの収入・支出・固定費をまとめ、次の支払いまでにあといくら必要かを教える。表示だけで、データは書き換えない

### 振り返り(知性レイヤー)
- **session-review(会話の振り返り)**: その日にやったことを、日付ごとの振り返りファイルに短く追記する。締めくくりの言葉で自動実行される
- **monthly-rollup(月次まとめ)**: 1か月分の振り返りを1つの要約ファイルにまとめ、元のファイルを保管用フォルダへ移す。月の最初の会話で提案される

### 毎日の使い始め
- **morning-sync(朝の同期)**: 携帯の Google スプレッドシートに書き溜めた記録(収入・支出・タスク)を、パソコンのデータファイルへ反映する。日付が変わって最初の会話で自動実行される
- **morning-briefing(朝のブリーフィング)**: 今日のタスク、Google カレンダーの予定、もうすぐ支払いの固定費を、短く1か所にまとめて表示する。表示だけで、何も書き換えない

## 連携している MCP サーバー

- **google-calendar-mcp(Google カレンダー連携)**: Google カレンダーの予定を読み書きするための接続。朝のブリーフィングで、今日の予定を取得するのに使う
- **mcp-google-sheets(Google スプレッドシート連携)**: Google スプレッドシートを読み書きするための接続。携帯から記録した受信箱のシートを読み、反映した行に「済」と書き込むのに使う

## 工夫した点

- **認証情報の分離**: Google の OAuth 認証情報は `credentials/` に分けて置き、Git の管理から外しています。API キーなどの秘密情報も、コードに直接書かず `.env` に分ける方針です。
- **`.gitignore` による秘密情報の除外**: `credentials/`、`.env`、`client_secret*.json` を除外しています。GitHub へ送る前に、送信対象の一覧と中身の両方を調べて、秘密情報が混ざっていないことを確かめています。
- **実データとサンプルの分離**: 実際の家計・タスクのデータは見せず、同じ構造の架空データを `samples/` に置いています。
- **固定費の土日調整**: 銀行振込・口座引き落としの固定費は、支払い日が土日なら次の月曜にずらして数えます。デビットカード払いは土日でもそのままです。固定費ごとに「ずらすかどうか」を持たせて、両方を正しく扱います。
- **月をまたぐ支払いの日数計算**: 「今日から何日後か」を、月をまたいでも正しく数えます(月末に、翌月1日の支払いも出る)。
- **二重登録の防止**: 朝の同期は、同期した日付を記録して同じ日に2回走らないようにしています。すでに同じ記録がある行は、勝手に追加せず報告に回します。
- **書き込む範囲の限定**: 同期でスプレッドシートに書くのは「処理済み」の列だけです。表示専用のスキルは、データを一切書き換えません。
- **操作の説明**: コードが読めなくても何をしているか分かるように、操作の前にやることを日本語で説明するルールにしています。

## データ構造を見たい場合

`samples/` フォルダに、架空の金額・内容のサンプルがあります。

- `samples/finance.json`: 収入・支出・固定費・時給の例
- `samples/tasks.json`: タスクの例

## フォルダ構成

- `CLAUDE.md`: 知識レイヤー(引き継ぎノート)
- `.claude/skills/`: スキルの手順書(9つ)
- `data/`: 実際のデータ置き場(中身は README・samples には載せていません)
- `reviews/`: 日々の振り返り(同上)
- `samples/`: 架空のサンプルデータ
